# GEMINI.md

## Project Overview

This project is a collection of Java practice problems. Each `Q*.java` file appears to be a self-contained exercise demonstrating a specific Java concept, from basic I/O and data types to method overloading and simple calculations. There is no overarching application or framework.

## Building and Running

Each Java file can be compiled and run independently.

**To compile a file:**

```bash
javac <filename>.java
```

**To run a compiled file:**

```bash
java <classname>
```

**Example:**

```bash
# Compile Q102.java
javac Q102.java

# Run the compiled Q102 class
java Q102
```

## Development Conventions

There are no formal development conventions apparent in this project. The code consists of simple, single-file programs. The naming convention for the files appears to be `Q` followed by a number (e.g., `Q102.java`).
